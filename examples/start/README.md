# First steps

Where to begin: one engine, one document, nothing to install. Read its log, then go on to any group.

| Example | What it is | Needs |
|---|---|---|
| [PRJEDU_101](PRJEDU_101/) | timers, scripts, a calculated value, an alarm with limits, and how to read the log | nothing |

Every example starts with one command from its own folder:

```bat
cd PRJEDU_101
run.bat
```

On Linux: `cd PRJEDU_101` and `./run.sh`. The engine and the licence are found in `../../../bin`, at the top of the repository.
